# Agent Behavioral Rules & Project Directives

## Live Browser Verification Evidence Rule
Whenever conducting live browser verification or E2E walkthroughs:
- Store and commit all walkthrough screenshots referenced in QA/verification reports directly into the repository under `docs/qa-evidence/`.
- Ensure report tables link directly to committed image paths (e.g., `[Step 1 Screenshot](docs/qa-evidence/01_initial_page.png)`) so independent reviewers can open and inspect the actual images directly in the repository rather than relying on local filenames alone.
